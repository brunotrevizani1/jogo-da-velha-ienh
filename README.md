🎮 Jogo da Velha

Este é um projeto de Jogo da Velha (Tic-Tac-Toe) desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de praticar conceitos fundamentais de desenvolvimento web e lógica de programação.

🚀 Funcionalidades
👥 Modo 2 jogadores (local)
🤖 Modo contra IA com 3 níveis de dificuldade:
Fácil (aleatório)
Médio (mistura de aleatório e estratégia)
Difícil (IA inteligente)
🧠 Sistema de verificação de vitória
🤝 Detecção de empate
📊 Placar funcional (X, O e empates)
🔄 Reinício automático do jogo
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript (puro)
🎯 Objetivo do projeto

Este projeto foi desenvolvido com o intuito de:

Praticar manipulação do DOM
Trabalhar com eventos de clique
Implementar lógica de jogo
Criar uma interface interativa
Introduzir conceitos básicos de inteligência artificial
🧠 Sobre a IA

A inteligência artificial possui três níveis:

Fácil: realiza jogadas aleatórias
Médio: alterna entre jogadas aleatórias e estratégicas
Difícil: utiliza lógica baseada em minimax, tornando-se praticamente imbatível
📁 Estrutura do projeto
index.html → modo 2 jogadores
ia.html → modo contra IA
style.css → estilização do jogo
script.js → lógica do jogo
💡 Possíveis melhorias
Animações ao jogar
Destaque visual para o vencedor
Efeitos sonoros
Salvamento de placar (localStorage)
📌 Considerações finais

Este projeto representa uma etapa importante no aprendizado de desenvolvimento web, reunindo conceitos de estrutura, estilo e comportamento em uma aplicação interativa simples, porém completa.
